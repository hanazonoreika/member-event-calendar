# 非公式 統合イベントカレンダー

でらっくすなボーイズでメンな方々のイベント情報をまとめて確認できる、非公式のファン向けカレンダーです。

ライブやイベント、メディア出演などの予定をチェックして、推し活のスケジュール管理に活用できます。

## ✨ このカレンダーでできること

- **イベント予定の確認**：公式サイトから取得した予定をまとめて表示します。
- **メンバー別の予定確認**：メンバーに関連するイベントをチェックできます。
- **イベントの詳細確認**：イベント名や開催日、公式情報へのリンクなどを確認できます。
- **チケット受付期間の確認**：取得できたチケット申込期間を、開催予定とは区別して確認できます。
- **手動予定の登録**：自分で予定を追加して、推し活のスケジュール管理に利用できます。

※実際に表示される情報や機能は、データの取得状況やカレンダーの仕様によって異なります。

## 📅 使い方

### 1. カレンダーを開く

公開されているカレンダーのURLにアクセスしてください。

### 2. 気になる予定を探す

カレンダーから日付ごとの予定を確認し、気になるイベントの詳細や公式リンクをチェックしてください。

### 3. 手動で予定を追加する

自分用の予定を登録する機能を利用できます。手動で追加した予定は、登録したブラウザ内に保存されます。

そのため、**別の端末やブラウザとは自動で同期されません**。ブラウザのデータを消去した場合などは、登録した予定が失われる可能性があります。

## 🔄 イベント情報の更新について

公式サイトからの情報取得とカレンダーの公開更新は、GitHub Actionsによって定期的に実行される仕組みです。

- 更新間隔：原則6時間ごと
- 情報源：BOYS AND MEN公式サイト、でらボ公式サイト
- 更新タイミング：アクセス状況などによって遅れる場合があります

カレンダーに予定が見当たらない場合や、情報が古い場合は、各公式サイトも確認してください。

## ⚠️ ご利用にあたって

- このカレンダーは**非公式のファン向けツール**です。元所属事務所・現会社・運営・各公式サイトとは関係ありません。
- すべてのイベント情報が掲載されることを保証するものではありません。
- 公式サイトの更新や仕様変更などにより、情報が正しく取得できない場合があります。
- 日付を確定できない告知などは、誤った日程で登録しないよう、自動登録されない場合があります。
- 開催日時、会場、出演メンバー、チケット受付期間、料金、参加条件などは、必ず公式の案内で確認してください。
- イベントの延期・中止・変更についても、公式発表を優先してください。

情報の正確性を確認するときは、公式サイトへのリンクもぜひ活用してください。
